# 폰트 라이선스

이 폴더의 웹폰트는 모두 [SIL Open Font License 1.1](https://openfontlicense.org/)로 배포되는 Google Fonts를 [@fontsource](https://fontsource.org/)를 통해 한국어(Hangul) 서브셋만 추출해 자체 호스팅한 것입니다.

| 파일 | 원본 폰트 | 제작자 |
|---|---|---|
| `gaegu-400.woff2` | Gaegu | Jeon Youngwoong |
| `dongle-400.woff2` | Dongle | Cadson Demak |
| `nanum-pen-script-400.woff2` | Nanum Pen Script | 네이버(NAVER) |
| `nanum-brush-script-400.woff2` | Nanum Brush Script | 네이버(NAVER) |

원본 라이선스 전문은 `node_modules/@fontsource/<패키지명>/LICENSE`에서 확인할 수 있습니다.
